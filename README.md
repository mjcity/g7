# Grade 7 study guides

Interactive math and life science guides for seventh-grade study.

## Quick start

- [Math: proportions](https://mjcity.github.io/g7/math/) — worked answers, guided methods, hints, and extra practice.
- [Science: cells](https://mjcity.github.io/g7/cells/) — plant and animal cells, animations, flashcards, practice, and a self-test.

Open either guide in a full browser with JavaScript enabled. The layout supports tablet portrait and landscape views. Practice progress stays in the browser and can be reset from each guide.

The math guide includes downloadable worked answers. Its original Google Fonts stylesheet has system font fallbacks. The cells guide is self-contained.

GitHub Pages publishes these static assets from the `main` branch. The original educational content and interactions are preserved; no child or school identities or saved learner answers are included.
